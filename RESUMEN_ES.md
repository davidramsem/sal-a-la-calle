# Sal a la calle CDMX — resumen

Planificador outdoor local: barrio + minutos + mood → tarjeta imprimible.

- Gemma 3 (4B por defecto, 1B opcional) vía Ollama, JSON estructurado
- Open-Meteo + OpenStreetMap / seed CDMX
- QR al mapa a pie, reto de campo offline, temporizador “phone-down”
- CLI + Gradio; modo `--offline`

Ver `README.md` y `article/DEV_POST_V2.md`.
